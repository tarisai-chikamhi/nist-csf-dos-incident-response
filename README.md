# NIST CSF DoS Incident Response Case Study

## Overview
This repository contains an incident response case study analyzing an
ICMP-based denial-of-service (DoS) attack that disrupted internal network
services. The incident is analyzed using the NIST Cybersecurity Framework
(Identify, Protect, Detect, Respond, Recover).

## Incident Summary
- Attack type: ICMP flood (Denial of Service)
- Impact: Internal network services unavailable for approximately two hours
- Root cause: Unconfigured firewall allowing unrestricted ICMP traffic

## Framework Applied
- Identify: Asset and vulnerability analysis
- Protect: Firewall hardening and traffic controls
- Detect: Network monitoring and IDS alerts
- Respond: Traffic blocking and service prioritization
- Recover: Service restoration and security improvements

- `incident-report.md` — Full NIST CSF incident analysis
- `README.md` — Project overview
